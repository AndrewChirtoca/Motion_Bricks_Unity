# Motion_Bricks_Unity

Unity 6000.3.10f1 prototype using the released GEAR-SONIC G1 planner through a local Python provider, plus an independent MotionBricks backbone pose-conditioning investigation.

See [quickstart](docs/quickstart.md), [implementation status](docs/implementation-status.md), [validation](docs/validation.md), and [model contract](docs/model-contract.md). Open the nested `Motion_Bricks_Unity` folder in Unity.

Planned next feature: [selectable inference backends](docs/inference-backends-plan.md) and the accompanying [benchmark tools and qualification protocol](docs/inference-benchmark-protocol-plan.md). These documents describe proposed work, not currently available backend options or commands.
